# Curriculum

Talos teaches programming through short, executable 3D challenges. Learners can solve each level with Blockly or Python and immediately observe the result in the Babylon.js scene.

## Foundations

1. **Functions** — call built-in commands, compose behaviors, and define reusable functions.
2. **For loops** — repeat movement, nest loops, and combine loops with functions.
3. **Conditionals** — branch with `if`, `elif`, and `else` based on world state.
4. **Logical operators** — combine conditions with `not`, `and`, and `or`.

## Programming patterns

5. **While loops** — repeat actions while a world-state condition remains true.
6. **Function parameters** — pass distances, provide defaults, and place characters by coordinate.
7. **Variables** — track collected coins, update values, and use `+=`.

## Data and world building

8. **Collections** — work with lists, dictionaries, tuples, and sets.
9. **Scene construction** — place tiles, coins, characters, and decorative objects.
10. **Structured worlds** — describe repeatable scene layouts with Python data structures.

The executable lesson copy and scene references live in `mocks/data/`.
